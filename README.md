# 双燃 Web

一个适配手机和桌面浏览器的双人自律锻炼竞赛 Web App。

## 使用方式

直接打开 `index.html` 即可使用。为了让手机和电脑都能访问，推荐启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 已实现

- 响应式首页比分面板
- 手机底部导航、桌面侧边导航
- 每日数据录入
- 图片上传与预览
- 本地保存记录
- 自动计算每周得分
- 本周战报与得分拆解
- 体脂趋势图
- 规则说明

数据会保存在浏览器 `localStorage` 中。
